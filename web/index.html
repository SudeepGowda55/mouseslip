Gongoozler is a small time-series language model that follows a chess game the way a spectator with no view of the board would. It reads White's clock, Black's clock and the evaluation bar, calls the next blunder before it happens and says why. Then Stockfish keeps score.

Every call, counted.

Watching without seeing.

A gongoozler is an idle spectator. This one cannot see the pieces. Scroll through one real game from the test set to see what it is given and how it is judged.

The dataset

lichess/clock-blunder on TimeNet: 60,358 windows cut from 15,205 real rated Lichess games. A window is up to 40 plies of three numbers per ply. No moves, no pieces, no board.

The fine-tuned model

OpenTSLM on Gemma-3-270M reads the three series and answers one question: will the player to move blunder within their next three moves? Then it gives its reason in a sentence.

The live watcher

On real Lichess games in progress it asks that question after every move. When the probability crosses the threshold it makes the call out loud, before the next move has been played.

The Stockfish referee

Stockfish then evaluates the mover's next three moves. Losing 0.30 or more winning chances in one move is a blunder and the call is a hit. Otherwise it is a miss. If the game ends first it is void.

What we found, plainly

The clocks alone add almost nothing beyond knowing the ratings and the time control. The evaluation bar carries the signal.
